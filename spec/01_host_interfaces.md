# ホストシェルインタフェース

> **信号名について**: 回路図 (kicad/host_shell.kicad_sch) のネット名では、ホストシェル固有の信号に
> `HS` プレフィックスが付く (例: `HSLCD_D0`、`HSAUX_SDA`、`HSTF_CSX`)。本仕様書では従来どおり
> `H` プレフィックスで表記する。また `LCTF_ENAX` は回路図上では `LCTF_ENX` と表記される。

## キーパッド

ボタン類は全て PCA9555 (devaddr=0x21) 経由で読み取られる (電源ボタンを除く。後述「電源I/F」)。
Home ボタンはホストシェル側の機能の呼び出しに使用する。

|GPIO|割り当て|説明|
|---|---|---|
|GPIO36|HAUX_SDA|I2C データライン|
|GPIO37|HAUX_SCL|I2C クロックライン|

|PCA9555ポート|割り当て|説明|
|---|---|---|
|P0_0|HKEY_L|左キー|
|P0_1|HKEY_R|右キー|
|P0_2|HKEY_U|上キー|
|P0_3|HKEY_D|下キー|
|P0_4|HKEY_A|Aボタン|
|P0_5|HKEY_B|Bボタン|
|P0_6|HKEY_X|Xボタン|
|P0_7|HKEY_Y|Yボタン|
|P1_0|HKEY_STA|STARTボタン|
|P1_1|HKEY_SEL|SELECTボタン|
|P1_2|HKEY_BL|Lバンパー|
|P1_3|HKEY_BR|Rバンパー|
|P1_4|HKEY_HOME|Homeボタン|

PCA9555 の残りのポートは制御出力として使用する。

|PCA9555ポート|割り当て|説明|
|---|---|---|
|P1_5|EXTVIDENX|外部ビデオ回路イネーブル (負論理)|
|P1_6|LCVSYSEN|LCVSYS 給電イネーブル (High=給電)|
|P1_7|HLCD_SPIEN|LCD SPI モード切替 (High=SPI)|

- PCA9555 の全ポートは内部プルアップ (約 100kΩ) を持つため、電源投入直後 (全ポート入力状態) の
  上記制御信号は High 相当となる。
- HKEY_D (下キー) は 1kΩ + ショットキーダイオードを介して RP2350B の QSPI_SS にも接続されており、
  下キーを押しながら電源投入 / リセットすると USB ブートモード (BOOTSEL) に入る。
- HKEY_BL / HKEY_BR は基板外実装のスイッチ用コネクタ (J2/J3) に接続される。
- HAUX (GPIO36/37) と LCAUX (GPIO28/29) はどちらも RP2350B の I2C0 にのみ割り当て可能なため、
  ファームウェアはピン機能を切り替えて時分割で使用する。
- HAUX バスには PCA9555 (0x21) のほか RTC (RV-3028-C7、0x52) が接続される (後述「RTC」)。

## LCD I/F

ILI9488 互換の 320x480 ドットの液晶を横に倒して使用する。通常は 8bit パラレル (8080) 接続。
D0-7 は HSTX 対応端子 (GPIO12-19) に割り当てており、将来的に外付け回路による DVI-D / NTSC
出力を試せるよう外部コネクタ (J5) にも引き出している (後述「外部ビデオ出力」)。

|GPIO|割り当て|説明|
|---|---|---|
|GPIO12-19|HLCD_D0-D7|データバス (HSTX 対応端子)|
|GPIO20|HLCD_DC|SPI モードではマルチプレクサでパネルから切り離される|
|GPIO21|HLCD_RST||
|GPIO22|HLCD_RD||
|GPIO23|HLCD_WR|SPI モード (4 線) では D/C として使用|
|GPIO24|HLCD_CS||
|GPIO27|HLCD_VSYNC|パネルの TE 出力 (ホスト側は入力)|
|GPIO46|HLCD_BL|バックライト PWM (High=点灯)|

### SPI モード

HLCD_SPIEN (PCA9555 P1_7) を High にするとパネルのインタフェースストラップが SPI に切り替わり、
パネルの DC/SCL 端子にはアナログマルチプレクサ (SN74LVC1G3157) 経由で HTF_SCK (GPIO34) が
接続される。シリアルデータは HTF_MOSI (GPIO35)。すなわち TF カードと SPI バスを共有する
(CS は HLCD_CS で独立)。4 線 SPI の D/C にはパネルの WR 端子 (HLCD_WR) を使用する。
パネルの SDO は接続していない (書き込み専用)。
HLCD_SPIEN 切り替え後は HLCD_RST でパネルをリセットすること。
D0-7 を外部ビデオ回路が使用している間、本体 LCD はこのモードで制御する。

### 外部ビデオ出力

HLCD_D0-7、HLCD_DC/RST/RD/WR/CS、VSYS、3.3V を外部コネクタ (J5) に引き出している。
EXTVIDENX (PCA9555 P1_5、負論理) で外部回路をイネーブルする。
DVI-D 出力時は D0-7 (HSTX) を 4 差動ペアとして使用する想定 (信号は外部回路側でバッファする)。

## TF カード I/F

SPI 接続。

|GPIO|割り当て|説明|
|---|---|---|
|GPIO32|HTF_MISO||
|GPIO33|HTF_CS||
|GPIO34|HTF_SCK||
|GPIO35|HTF_MOSI||
|GPIO42|HTF_DETX|カード検出。Low=挿入 (基板上でプルアップ)|

- MISO/SCK/MOSI は LCD の SPI モードとバスを共有する (CS は別)。
- ロジックカードへの接続切り替え (LCTF_ENAX) は [02_wildcardbus.md](02_wildcardbus.md) を参照。

## オーディオ I/F

|GPIO|割り当て|説明|
|---|---|---|
|GPIO44|HAUDIO_L|PWM オーディオ出力 (左)|
|GPIO45|HAUDIO_R|PWM オーディオ出力 (右)|

- PWM 出力はシュミットトリガバッファで整形後、RC フィルタ (fc ≈ 7kHz) で平滑され、
  ロジックカードのオーディオ (LCAUDIO_L/R) と抵抗ミックスされる。
- ミックス後の信号は音量ボリュームを経てスピーカアンプ (LM4890 BTL x2) と
  ヘッドホンアンプ (LM4880) に入る。ヘッドホンジャックの挿入検出により
  スピーカ / ヘッドホンはハードウェアで自動的に切り替わる (GPIO 制御不要)。

## 電源I/F

電源系統: VBUS (USB) と VBAT (Li-Po) をダイオード OR した電源を、電源ボタン付きロードスイッチ
(XC6194) を通して VSYS とし、昇降圧 DCDC (TPS63802) で 3.3V を生成する。
充電は MCP73831 (約 370mA)。
電源ボタンのクリックは GPIO41 (BTN_PWRX) で検知し、ファームウェアが後始末をしてから
SYSSD で自己遮断する (安全なシャットダウン)。長押しは XC6194 のハードウェア機能による
強制電源断で、ファームウェアが暴走していても機能する。

|GPIO|信号名|説明|
|---|---|---|
|GPIO39|SYSSD|High でシステム電源断 (XC6194 SHDN)|
|GPIO41 (ADC1)|BTN_PWRX|電源ボタン検知 (Low=押下)。3.3V に 100kΩ でプルアップし、ショットキーダイオード経由で BTN_PWRX ノード (VCOM 系、最大約 4.2V) から絶縁|
|GPIO43 (ADC3)|ADCBAT|バッテリー電圧監視 (VBAT の 1/2 分圧。システム OFF 中は分圧回路ごと切り離される)|

- 電源ボタンで電源 ON した直後はボタンが押されたままのため BTN_PWRX は Low で起動する。
  ファームウェアは一度 High (離した状態) を確認してからクリック検知を有効にすること。
  チャタリング除去もソフトウェアで行う (BTN_PWRX ノードにコンデンサはない)。

ロジックカードへの電源供給:

|電源|制御|説明|
|---|---|---|
|LC3V3|なし|ホストシェル動作中は常時給電|
|LCVSYS|LCVSYSEN (PCA9555 P1_6)|High で給電。ソフトスタート付き|

## RTC

RV-3028-C7 (I2C devaddr=0x52) を HAUX バス (GPIO36/37) に接続している。

|項目|内容|
|---|---|
|VDD|3.3V|
|VBACKUP|VBAT (ヒューズ F2 の下流)。システム OFF 中もバッテリーから時刻保持 (約 45nA)|
|INT|未使用 (テストポイントのみ)。アラームフラグは I2C ポーリングで読む|
|CLKOUT|未使用 (テストポイントのみ)|
|EVI|10kΩ プルダウン (未使用)|

ファームウェアでの初期化時の注意:

- バックアップ切替 (BSM) は POR デフォルトで無効。EEPROM 設定で DSM または LSM を
  一度書き込むこと (EEPROM 保持のため以後は不要)。
- トリクル充電は無効のまま使用する (VBACKUP が Li-Po 直結のため)。
- CLKOUT はデフォルトで 32.768kHz を常時出力するため、無効化して消費電流と輻射を抑える。
- devaddr 0x52 は Xiamocon カードのバッテリー監視 ADC (ADC101C027) と同値だが、
  あちらはカード側バス ([04_host_controller.md](04_host_controller.md) 参照) 上の
  エミュレーションであり、バスが異なるため衝突しない。
