# ホストコントローラ

## 起動

起動時、ロジックカードの EEPROM からカードプロファイルを読み出し、カードの種類を判別する。
カードプロファイルに応じて、ロジックカードの LCD I/F、キーパッド I/F、TF カード I/F の接続方法を切り替える。
ロジックカードを検出できなかった場合は「システムメニュー」を起動する。

## システムメニュー

起動時は「システムメニュー」が動作する。

メニューの階層構造:

- ホーム画面
  - `Start card` / `Stop card`: ロジックカードを起動 / 停止する (状態に応じてどちらか一方が表示される。後述「ロジックカードの状態」)
  - `Apps`:
    - <ファイルブラウザ>: TF カードの `WCB/Cards/<カードID>/Apps/` からバイナリファイルを選択後、ロジックカード上の MCU に書き込む。
      書き込みはロジックカード停止中に行い、完了後にロジックカードを起動するかどうかをユーザに確認する。
  - `Profile`:
    - <ファイルブラウザ>: TF カードの `WCB/Cards/` からカードプロファイル (`profile.hex`) を選択後、ロジックカードのカードプロファイルチップに書き込む。
      書き込み後はロジックカードの検出をやり直す。

ロジックカードが TF カードを占有している間 (動作中かつ `useTfCard`) は、`Apps` / `Profile` は使用できない (先に停止する)。

## ファイルブラウザ

システムメニューから呼び出す形で、TF カード上のファイルシステムをブラウズすることができる。
Windows の「開く」ダイアログのイメージ。

LCTF_ENAX=High にした上で HTF_xxxx 端子を使って TF カードにアクセスする。
ロジックカードが TF カードを占有している間は、ホストコントローラは TF カードにアクセスできない。

画面の一番上に現在のディレクトリパスを表示し、その下にディレクトリ内のファイル/ディレクトリをリスト表示する。

上下キーで選択カーソルを移動。
左キーで親ディレクトリに移動。
右キーで選択された子ディレクトリに移動。
B キーで親ディレクトリに移動。
ファイル選択が要求されているときに子ディレクトリを選択して A キー: 子ディレクトリに移動する。
フォルダ選択が要求されているときにファイルを選択して A キー: 無視
要求された種類の項目が選択された状態で A キー: 当該項目を開くかどうかの確認ダイアログを表示し、A キーで開く、B キーでキャンセル。

画面一番下に操作説明を表示:

```
U/D:Select  L:Parent  R:Child  A:Open  B:Cancel
```

## ロジックカードの状態

ロジックカードには「停止」と「動作」の 2 状態がある。

|状態|RESET|LCTF_ENAX|説明|
|---|---|---|---|
|停止|アサート|High|ロジックカード上の MCU はリセット状態。本体は TF カードにアクセスできる。将来的にはロジックカードへの 5V 供給もここで停止する|
|動作|デアサート|`useTfCard` なら Low、それ以外は High|ゲームモード。`useTfCard` の場合、本体側の HTF_xxxx 端子は High-Z にし、本体から TF カードにはアクセスしない|

- 本体起動時に既にロジックカードが挿さっていた場合は、プロファイル検出後に自動的に「動作」へ移行する。
- 本体起動後にロジックカードが挿された場合、およびアプリ書き込みの完了後は「停止」のままとし、ロジックカードを起動するかどうかをユーザに確認する (A: 起動 / B: 停止のまま)。
- システムメニューの `Start card` / `Stop card` で状態を切り替える。
- アプリ書き込み (ISP) の間は、ISP プロトコルが要求するとおりに RESET / BOOTSEL を操作する。

### USB (MSC) によるアプリ書き込み

`isp.method` = 16 のロジックカード (RP2040 / RP2350 など) では、次の手順で UF2 ファイルを書き込む。

1. 停止状態 (RESET アサート) から BOOTSEL をアサートし、RESET をデアサートして MCU を起動、その後 BOOTSEL をデアサートする。
2. ホストコントローラが USB ホスト (LCUSB_DP/DM) として MCU の USB MSC デバイスをマウントする。
3. UF2 ファイルの各 512 バイトブロックを MSC デバイスに書き込む。
4. MCU はすべてのブロックを受け取ると Flash への書き込みを終えて再起動し、USB から切断される。ホストコントローラはこの切断をもって書き込み完了とみなす (タイムアウトあり)。
5. RESET をアサートして停止状態に戻す。

### UART によるアプリ書き込み

`isp.method` = 2 のロジックカード (ESP8266 など) では、UART 経由で Espressif シリアルブートローダプロトコル (SLIP フレーミング) により書き込む。
ホスト側の実装には Espressif 公式の esp-serial-flasher の移植を想定する。

1. 停止状態 (RESET アサート) から BOOTSEL (ESP8266 の GPIO0) をアサートし、RESET をデアサートして MCU を UART ダウンロードモードで起動する。その後 BOOTSEL をデアサートする。
2. 115200 bps で SYNC を行い、スタブローダを RAM へ転送・起動してボーレートを 921600 bps へ切り替える。
3. バイナリファイルを Flash オフセット 0x0000 から書き込む (圧縮転送)。書き込み後、MD5 コマンドで検証する。
4. RESET をアサートして停止状態に戻す。

UART TX/RX のホスト側ポートは書き込み中のみ駆動し、それ以外の期間は High-Z とする
(ESP8266 の RXD0 が浮かないよう、ロジックカード側にプルアップを実装すること)。

## 仮想 I/O エキスパンダ

`lcio.useVirtIoExp` が true のロジックカードでは、ホストコントローラは GPIO6/7 (LCVIO_SDA/SCL) を I2C1 スレーブとして動作させ、
`virtIoExp.chip` で指定されたチップのレジスタ動作を模擬する。
ロジックカードの動作中は常に応答する (システムメニュー表示中を含む)。

### MCP23017 の模擬 (`chip` = "mcp23017")

- スレーブアドレスは `virtIoExp.addr` (通常 0x20 = 32)。それ以外のアドレス宛の転送には応答しない (NACK)。
  同一バス上に存在し得る他チップ (ESPboy の MCP4725 など) は模擬しない。
- IOCON.BANK = 0 のレジスタマップ (0x00-0x15) を実装する。レジスタポインタは STOP をまたいで保持し、
  連続アクセスで自動インクリメントする (SEQOP = 0 前提)。
- GPIOA/B の読み出し値のうち、LCIO64-79 にキーが割り当てられたビットにはキーパッド状態を反映する
  (キーマップと負論理指定に従う)。未割り当ての入力ビットは 1 (プルアップ相当) を返す。
- 出力に設定されたピンへの書き込みは OLAT に保持し、読み戻せるようにする。ホストは出力値を使用しない。
- IODIR/GPPU/IPOL 等の設定レジスタは保持・読み戻しのみ行い、入力値の生成には影響させない。
- INTA/INTB 割り込み出力は模擬しない。
- カード起動時 (RESET デアサート時) にレジスタを Power-on 初期値へ戻す。

### PCA9555 の模擬 (`chip` = "pca9555")

- スレーブアドレスは `virtIoExp.addr` (Xiamocon は 0x22 = 34)。それ以外のアドレス宛の転送には応答しない (NACK)。
  同一バス上に存在し得る他チップ (Xiamocon のバッテリー監視 ADC ADC101C027 (0x52) など) は模擬しない。
- コマンドレジスタ 0-7 (Input 0/1、Output 2/3、Polarity Inversion 4/5、Configuration 6/7) を実装する。
  Power-on 初期値は Output = 0xFF、Polarity = 0x00、Configuration = 0xFF (全入力)。
- レジスタポインタは STOP をまたいで保持する。連続アクセス時のオートインクリメントは
  レジスタペア内でのトグルとなる (0↔1、2↔3、4↔5、6↔7。MCP23017 の連番インクリメントとは異なる)。
- Input レジスタの読み出し値は、入力設定ビットはパッドレベル (キー割り当てと負論理指定に従う。
  未割り当てビットは 1 = プルアップ相当)、出力設定ビットは Output レジスタ値とし、
  その全体に Polarity Inversion レジスタによる反転を適用する:
  `Input = ((levels & Config) | (Output & ~Config)) XOR Polarity`。
  **MCP23017 の模擬と異なり、極性反転を入力値の生成に反映する** (将来のカードでの使用を想定)。
- Output レジスタへの書き込みは保持し、読み戻せるようにする。
  機能番号 1 (ディスプレイリセット) が割り当てられた仮想ポート ([03_card_profile.md](03_card_profile.md)) については、
  Configuration で出力に設定されたビットの Output 値が Low の間、LCD をリセット状態として LcdTap へ転送する
  (`inputReset()` 相当)。この転送は段階的対応とし、未対応のホストは当該ポートを無視してよい。
- INT 割り込み出力は模擬しない。
- カード起動時 (RESET デアサート時) にレジスタを Power-on 初期値へ戻す。

## ゲームモード

本体側のキーパッド入力をロジックカードに送信する。
ロジックカードからの LCD 描画命令は LcdTap (submodule/lcdtap/) で受けてフレームバッファに描画し、本体側の LCD に表示する。
本体側 LCD への転送は、フレームバッファの更新された部分のみに対して行う。

ホームボタンが押されたらフレームバッファの表示は中止してシステムメニューを表示する。
システムメニュー表示中もロジックカードは動作を続ける。
もう一度ホームボタンが押されたらシステムメニューを閉じてフレームバッファの表示を再開する。
