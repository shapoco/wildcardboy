About

Edits the card profile stored in the logic card's EEPROM (see spec/03_card_profile.md). Export HEX writes the EEPROM image (4-byte length, CBOR, CRC32) as Intel HEX, to be placed on the TF card and written to the card by WildCardBoy. The JSON on the right is the same profile in readable form; both sides stay in sync.
